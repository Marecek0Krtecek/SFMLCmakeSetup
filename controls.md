# 🎮 Klávesové skratky v Level Editore

## Základné
- **Ctrl + S** — Uložiť level  
- **Ctrl + Shift + S** - Uložiť level ako
- **Ctrl + O** — Otvoriť level  
- **Ctrl + N** — Nový level  

## Platformy
- **P** — Pridať platformu  
- **Ctrl + D** — Duplikovať označenú platformu  
- **Ctrl + X** — Zmazať označenú platformu alebo spawn point

## Nepriatelia
- **Ctrl + E** — Pridať nepriateľa  
- **Ctrl + Shift + D** — Duplikovať spawn point  

## Editor
- **Ctrl + Z** — Undo  
- **Ctrl + Y** — Redo  
- **F1** — Zobraziť pomoc / legendu
- **Esc** - Opustiť editor do hlavného menu
- **Q** - Zoom -
- **E** - Zoom +

## Zmena Editora / Hry
- **F5** - Zmena módu na opačný

## Myš
- **Ctrl + LButton** - Uloženie pozície z canvasu
